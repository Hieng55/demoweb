Website Developer
Fresher.

Tự triển khai giao diện responsive, tích hợp các tính năng phổ biến và kiểm tra chất lượng trước khi gửi review trên những dự án website thực tế.

Lương dự kiến8–12 triệu đồng gross/tháng
Lịch làm việcThứ Hai – Thứ Sáu, 09:00 – 17:00
Hình thứcToàn thời gian tại TP.HCM
Chế độBHXH, BHYT, BHTN theo quy định

Công việc chính

  • Phát triển giao diện responsive từ Figma và component có thể tái sử dụng.
  • Tích hợp API, form, tracking cơ bản và CMS khi dự án yêu cầu.
  • Tối ưu Core Web Vitals, accessibility và SEO kỹ thuật nền tảng.
  • Kiểm thử, sửa lỗi, dùng Git và viết hướng dẫn bàn giao ngắn gọn.

Yêu cầu ứng viên

  • Vững HTML, CSS, JavaScript; đã dùng React hoặc framework tương đương.
  • Hiểu responsive, REST API, Git và cách triển khai một website.
  • Có portfolio hoặc GitHub cho thấy phần việc do chính bạn thực hiện.
  • Biết đọc tài liệu, chia nhỏ vấn đề và chịu trách nhiệm với deadline.

Quyền lợi & lộ trình

  • Lương dự kiến 8–12 triệu đồng gross/tháng theo bài thực hành và năng lực.
  • Tham gia BHXH, BHYT và BHTN khi ký hợp đồng thuộc diện tham gia.
  • Hỗ trợ thiết bị, công cụ, onboarding và review chuyên môn.
  • Có mục tiêu năng lực rõ để review lên Website Developer Junior.
